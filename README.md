# Entre Capítulos — Dark

Nova versão separada do site antigo, criada para funcionar bem no Android e no computador.

## Arquivos principais
- `index.html` — início
- `explorar.html` — busca e gêneros
- `biblioteca.html` — salvos e continue lendo
- `livro.html` — página do livro
- `leitura.html` — leitor de capítulos
- `atualizacoes.html` — novos capítulos
- `perfil.html` — perfil do usuário
- `painel.html` — painel do autor
- `login.html` / `cadastro.html` — autenticação visual

## Nesta primeira versão
Os dados funcionam com `localStorage`, então você já consegue testar a navegação sem Firebase.
